## Purpose

This section stores all quality gate and process checklists used to validate that work meets Alkanetic standards before proceeding through key delivery milestones.

---

## Scope

Checklists in this section are used at defined points in the engineering and delivery lifecycle — before code review, before deployment, at project close, and so on.

---

## What Belongs Here

- Pre-merge / code review checklists
- Pre-deployment checklists
- Architecture review checklists
- Security review checklists
- Project kick-off and close checklists
- Documentation review checklists
- BA requirements review checklists

---

## What Does Not Belong Here

- Templates (see `../templates/`)
- SOPs (see `../sop/`)
- Standards documents (see their respective sections)
