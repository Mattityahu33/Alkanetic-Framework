# Documentation Standards

**Status:** Scaffold
**Owner:** Alkanetic Engineering
**Last Updated:** 2026-08-02

---

## Purpose

This section defines how all framework and project documentation is written, structured, versioned, reviewed, and maintained across Alkanetic.

---

## Scope

Applies to all contributors creating or maintaining documentation within the Alkanetic Framework and across all associated project repositories.

---

## What Belongs Here

- Document naming and structure conventions
- Writing style and tone guidelines
- Metadata standards (see also `.metadata-template.md` at the root)
- Document lifecycle management (draft → review → approved → deprecated)
- Version control standards for documents
- Review and approval procedures for documents
- Glossary maintenance standards

---

## What Does Not Belong Here

- Document templates themselves (see `../templates/`)
- Engineering coding standards (see `../engineering-standards/`)
- Project-specific documentation (project repositories)

---
