## Purpose

This section stores completed, annotated reference examples that demonstrate how Alkanetic standards, templates, and processes are applied in practice.

---

## Scope

Examples serve as reference material for engineers, analysts, and new team members to understand how abstract standards translate to real artefacts.

---

## What Belongs Here

- Completed and annotated example documents (ADRs, user stories, technical specs)
- Example project structures
- Example CI/CD configurations
- Example code review feedback
- Example architecture diagrams with written explanation

---

## What Does Not Belong Here

- Live or production project documents (project repositories)
- Blank templates (see `../templates/`)
- Standards and SOPs (see their respective sections)
