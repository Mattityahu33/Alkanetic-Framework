# Assets

**Status:** Scaffold
**Owner:** Alkanetic
**Last Updated:** 2026-08-02

---

## Purpose

This section stores all static visual and brand assets used across the Alkanetic Framework documentation, presentations, and external communications.

---

## Scope

All Alkanetic-owned visual assets that are shared or reused across multiple contexts belong here.

---

## Subfolder Structure

| Subfolder        | Purpose                                                                     |
| ---------------- | --------------------------------------------------------------------------- |
| `branding/`      | Brand identity files (brand guidelines summary, colour palette, typography) |
| `logos/`         | Logo files in all approved formats and variants                             |
| `icons/`         | Icon sets used in framework documentation or products                       |
| `screenshots/`   | Application and UI screenshots for documentation                            |
| `diagrams/`      | Architecture, flow, and process diagrams                                    |
| `presentations/` | Slide decks and presentation assets                                         |

---

## What Does Not Belong Here

- Project-specific assets (store in project repositories)
- Confidential visual assets (store in appropriate secured location)
- Code or binary application files
