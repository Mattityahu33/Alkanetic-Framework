## Archiving Process Summary

When a document is to be archived:

1. Move the file from its original section into `archive/`.
2. Add `archived: YYYY-MM-DD` to the YAML front matter.
3. Add `archive-reason: <reason>` to the YAML front matter.
4. Update the original section `INDEX.md` to note the document as archived.
5. Update `registry/` to mark the document status as `archived`.
6. Record the action in `CHANGELOG.md`.
