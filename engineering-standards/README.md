# Engineering Standards

**Status:** Scaffold
**Owner:** Alkanetic Engineering
**Last Updated:** 2026-08-02

---

## Purpose

This section defines the engineering standards that govern how software is written, reviewed, tested, and maintained across all Alkanetic projects.

---

## Scope

All Alkanetic engineers are expected to understand and apply the standards contained in this section. These standards apply to all production codebases and internal tooling.

---

## What Belongs Here

- Coding standards per language and framework
- Branching and version control standards
- Code review standards and checklists
- Testing standards (unit, integration, end-to-end)
- Performance standards
- Accessibility standards
- Dependency management standards
- Tooling and environment standards

---

## What Does Not Belong Here

- Architecture decisions (see `../architecture/`)
- Deployment procedures (see `../deployment/`)
- Security standards (see `../security/`)
- Project management processes (see `../project-management/`)
- Templates and checklists (see `../templates/` and `../checklists/`)
