# Security

**Status:** Scaffold
**Owner:** Alkanetic Engineering
**Last Updated:** 2026-08-02

---

## Purpose

This section defines the security standards, threat modelling processes, and compliance requirements that govern how Alkanetic builds and operates secure systems.

---

## Scope

Applies to all engineers, architects, and DevOps practitioners involved in designing, building, or operating Alkanetic systems and infrastructure.

---

## What Belongs Here

- Secure coding standards
- Threat modelling methodology
- Authentication and authorisation standards
- Data protection and privacy standards
- Secret and credential management standards
- Vulnerability management process
- Security review and audit procedures
- Incident response framework (security-specific)

---

## What Does Not Belong Here

- General engineering coding standards (see `../engineering-standards/`)
- Deployment procedures (see `../deployment/`) unless security-specific
- Governance policies (see `../governance/`)
